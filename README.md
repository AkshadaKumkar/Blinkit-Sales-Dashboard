#Blinkit Sales Dashboard
#Project Overview

This project analyzes Blinkit's grocery sales data using Power BI.
The dashboard provides insights into sales performance, product categories, outlet performance, customer ratings, and inventory trends.

#Objectives
- Analyze Total Sales
- Compare Product Categories
- Evaluate Outlet Performance
- Analyze Customer Ratings
- Identify Best Selling Products
